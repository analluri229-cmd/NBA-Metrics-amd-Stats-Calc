What the pipeline does

  • Bootstraps the SQLite warehouse schema
  • Creates canonical team, player, and date mappings
  • Loads historical sample data into fact tables
  • Loads live sample feed data into the same fact tables
  • Creates a foundation for rolling feature generation and modeling
